# CodeAlpha - Image Gallery 📸

A responsive, curated image gallery web application built with modern HTML5, CSS3, and vanilla JavaScript. Features dynamic category filtering, a full-featured lightbox viewer with smooth transitions, keyboard navigation, and responsive mobile-first design.

---

## ✨ Features

- **Responsive Grid Layout**: Auto-fitting responsive grid that adapts across mobile, tablet, and desktop screens.
- **Dynamic Category Filtering**: Seamlessly filter curated photography by categories (*All, Nature, Architecture, Travel, Animals*) with instant visual transitions.
- **Interactive Lightbox Modal**:
  - Full-resolution preview of images.
  - Previous and Next navigation buttons with cyclic looping.
  - Dynamic image counter (e.g., `3 / 12`).
  - Keyboard accessibility (Left Arrow, Right Arrow, and `Escape` key to close).
  - Background overlay click-to-close.
- **Fallback Image Handling**: Built-in fallback mechanism ensuring no broken images are ever displayed.
- **Polished Glassmorphism & Micro-animations**: Modern aesthetic with soft shadows, smooth hover zoom effects, and clean typography via *Plus Jakarta Sans*.
- **Mobile Responsive Navigation**: Accessible hamburger toggle menu for smaller viewports.

---

## 🛠️ Built With

- **HTML5**: Semantic markup with ARIA roles for accessibility.
- **CSS3**: Custom CSS grid, flexbox, CSS variables, glassmorphism, and responsive media queries.
- **JavaScript (ES6+)**: Vanilla JS DOM manipulation, modal state management, event delegation, and keyboard listeners.
- **Typography & Icons**: Plus Jakarta Sans via Google Fonts, custom vector SVG icons.
- **Photography**: High-resolution photography from Unsplash.

## 🚀 Getting Started

No build tools, bundlers, or package installations required!

### Option 1: Direct Run
1. Clone the repository:
   ```bash
   git clone https://github.com/Shubhamwadhe111/CodeAlpha_-Image-Gallery-.git
   ```
2. Open `index.html` directly in your browser of choice (Chrome, Edge, Firefox, Safari).

### Option 2: Live Server (VS Code)
1. Open the folder in VS Code.
2. Right-click `index.html` and click **"Open with Live Server"**.
